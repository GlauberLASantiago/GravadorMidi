# 🎹 Estúdio MIDI Online

O **Estúdio MIDI Online** é uma aplicação web interativa que simula um piano virtual diretamente no navegador, permitindo tocar, gravar, reproduzir, quantizar e exportar composições em formato **MIDI**. O projeto foi desenvolvido com uma interface moderna em estilo **neo-brutalista pastel**, oferecendo uma experiência visual agradável e intuitiva para estudo, prática e criação musical.

## ✨ Funcionalidades

- Piano virtual com teclas visuais interativas
- Suporte a teclado do computador (**QWERTY**)
- Compatibilidade com dispositivos **MIDI externos**
- Seleção de instrumentos **General MIDI**
- Gravação de notas em tempo real
- Reprodução da gravação realizada
- Metrônomo embutido com controle de:
  - BPM
  - fórmula de compasso
- Quantização dinâmica das notas
- Exportação da gravação em arquivo **`.mid`**
- Alteração de oitava
- Interface responsiva e estilizada com **Tailwind CSS**

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Tailwind CSS**
- **Web Audio API**
- **Web MIDI API**
- **Soundfont Player**
- **MidiWriterJS**

## 🎼 Como usar

1. Abra o projeto em um navegador compatível.
2. Toque usando:
   - o mouse nas teclas do piano,
   - o teclado do computador,
   - ou um teclado MIDI conectado.
3. Escolha o instrumento desejado.
4. Ajuste o metrônomo, BPM e compasso.
5. Clique em **Gravar** para iniciar a captura.
6. Toque sua melodia.
7. Clique em **Parar** para finalizar.
8. Use **Play** para ouvir a reprodução.
9. Clique em **Baixar .MID** para exportar sua composição.

## ⌨️ Controles

- **Teclado QWERTY**: usado para tocar notas musicais
- **Botões de oitava**: alteram a região das notas
- **Gravar / Play / Parar / Limpar**: controlam a sessão de gravação
- **Quantização**: ajusta as notas para divisões rítmicas
- **Metrônomo**: auxilia na precisão rítmica

## 🌐 Compatibilidade
